Every command supports `-h`/`--help`. List and get commands accept
`-o table|json|yaml`.

## Identity & connectivity

```bash
nginxpm status -o json         # server status; no authentication required
nginxpm user current -o json   # current authenticated user
nginxpm config list-profiles   # saved connection profiles
```
